The Fluxzero SDK lets you build application behavior in Java or Kotlin. Messages express actions and questions,
handlers execute them, and Models remember the resulting state. Fluxzero provides delivery, persistence and testing
around that code, so these parts work together in one application.

These developer guides explain that programming model and how to build with it. Start with the concepts, learn through
a tutorial, then use a focused guide or the reference for the feature you are building.

## Reference

The reference explains the SDK's parts, starting with their ordinary use and then refining their behavior.

### Messaging

Messages connect your application's behavior: commands request an action, queries request information and events
report what happened. Start with [sending](/docs/guides/messaging/sending-messages) and
[handling](/docs/guides/messaging/message-handling), then explore
[consumers](/docs/guides/messaging/message-tracking), [scheduling](/docs/guides/messaging/message-scheduling),
[HTTP](/docs/guides/messaging/handling-web-requests) and [WebSockets](/docs/guides/messaging/handling-websocket-messages).
Validation, access control, interceptors and observability refine those flows.

### Modeling & persistence

Models give domain state an identity and lifecycle. [Apply changes](/docs/guides/modeling-and-persistence/updating-entities),
[connect related Models](/docs/guides/modeling-and-persistence/nested-entities), and use
[Graphs](/docs/guides/modeling-and-persistence/temporal-graphs) to navigate their relationships and history.
[Persistence](/docs/guides/modeling-and-persistence/model-persistence),
[search](/docs/guides/modeling-and-persistence/document-index-and-search) and
[stateful handlers](/docs/guides/modeling-and-persistence/stateful-handlers) support storing, finding and coordinating state.

### Data control & serialization

Control which data is stored and what readers can see. Learn to
[protect sensitive fields](/docs/guides/data-control-and-serialization/protecting-sensitive-data),
[evolve stored data](/docs/guides/data-control-and-serialization/upcasting-and-downcasting) and
[filter responses per user](/docs/guides/data-control-and-serialization/user-based-content-filtering).
