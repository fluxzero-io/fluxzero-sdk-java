# Your first Fluxzero handler

Let’s make sure everything’s working.

In this mini-tutorial we're going to create the simplest possible Fluxzero app — just a single HTTP endpoint.



---

## 1. Create a project

If you haven’t created a project yet, follow the [installation guide](/docs/getting-started/installation) first.

Open the generated Basic Starter project in your editor. Its Spring setup discovers handler classes in the application's root package.

---

## 2. Add an endpoint

Create a file named `HelloEndpoint.java` (or `.kt`) in the root package:

<Tabs>
  <TabItem label="Java">

  ```java
  @Component
  public class HelloEndpoint {

      @HandleGet("/hello")
      public String hello() {
          return "Hello from Fluxzero!";
      }
  }
  ```

  </TabItem>
  <TabItem label="Kotlin">

  ```kotlin
  @Component
  class HelloEndpoint {

      @HandleGet("/hello")
      fun hello(): String {
          return "Hello from Fluxzero!"
      }
  }
  ```

  </TabItem>
</Tabs>

`@HandleGet("/hello")` connects the path to the method. The returned string becomes the HTTP response body.
`@Component` lets the starter's Spring setup register this handler. Outside Spring, register a handler instance
[explicitly](/docs/guides/configuration/configuring-fluxzero).

---

## 3. Run your app

From the project directory, start the local development environment:

```bash
fz dev
```

Open the application URL shown by the CLI and append `/hello`. The
[local development guide](/docs/building/local-development) explains the Devboard and preview.

You should see:

```
Hello from Fluxzero!
```

---

## 4. What's next?

You’ve just added your first Fluxzero handler!

Continue with [Core concepts](/docs/getting-started/core-concepts) to add stored state and commands,
or build the [to-do app](/docs/tutorials/first-app) step by step.
