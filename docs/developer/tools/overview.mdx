<details>
<summary id="versions-belong-to-components">Which component does an update change?</summary>

CLI, Dev Server, SDK and agent plugin have separate release versions. A CLI update does not migrate your app to a new SDK. Use project pins and version-matched documentation, and check the installed tool's help when options differ. See [Install and update](/docs/tools/install).

</details>
