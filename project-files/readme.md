# Fluxzero Java SDK - Project Files

This folder contains project files for AI coding assistants working on projects built upon the SDK in this repository.
Note that these files are not for building the SDK itself.

The canonical agent documentation is now the graph in [`docs/agents`](../docs/agents/README.md), alongside the human
documentation in `docs/developer`. These Java/Kotlin trees remain for existing `project-java.zip` and
`project-kotlin.zip` consumers until their download and MCP integrations migrate. Do not remove or change those
archive layouts as part of a graph-only edit; keep relevant compatibility guidance current while they are supported.
